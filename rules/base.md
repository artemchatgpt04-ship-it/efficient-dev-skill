# Base rules

- Respect user, repository, and environment instructions before optimizing work.
- Start with the smallest evidence-backed scope and expand it when dependencies, risk, uncertainty, or failures require more context.
- Treat routing, cache, and test plans as recommendations, never as hard limits.
- Read current source when exact code or edit context is required; never use stale cached knowledge.
- Keep generated runtime state under the target project's `.efficient-dev/` and do not assume it is safe to commit.
